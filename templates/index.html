How these numbers are made

  • Source. The same strategy code that runs the live paper-trading bot, applied directly to the index / ETF price series (30-minute bars) instead of to stocks. No proxy stocks are used anywhere on this page.
  • Trades. Each strategy holds at most one position. A trade's return is exit close ÷ entry close − 1, minus {{ "%.2f"|format(meta.cost_round_trip_pct) }}% round-trip cost. Different strategies can hold the same index at the same time.
  • Portfolio. Strategy weights {% for k, v in meta.weights.items() %}{{ k }} {{ v }}%{{ ', ' if not loop.last else '' }}{% endfor %}, rebalanced to target at each new month (0.30% on the amount moved). The stock-basket rotation strategy of the live bot is left out because it is not index-level.
  • Marking. Every position, including trades still open at the cutoff, is valued at each day's last close, so drawdowns include open losses. Sharpe and Sortino use daily returns × √252, risk-free rate 0. Benchmark: {{ meta.benchmark }} (no dividends).
  • Testing. Rules were developed on {{ meta.start[:4] }}–{{ meta.rules_fixed_through[:4] }} and fixed on {{ meta.rules_fixed_through }}; later months are out of sample. Results are a model, not audited or broker-reported returns, and past results don't predict future ones.
  • Delay. By design, the page is refreshed each trading evening but only shows data up to {{ meta.lag_days }} days ago.
